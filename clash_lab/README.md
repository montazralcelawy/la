# Clash Automation Lab — إعادة البناء

نواة جديدة مستقلة عن ملفات الإصدار القديم، مع أولوية UiAutomator2 واستخدام ADB كطبقة اتصال واحتياط. تستخدم الرؤية الحاسوبية وOCR عند الحاجة فقط.

## المتطلبات
- Windows 10/11
- Python 3.10 أو أحدث (يفضّل 3.11)
- Android emulator أو جهاز Android مع تفعيل ADB
- Android Platform Tools (`adb`) ضمن PATH أو تحديد مساره من الإعدادات لاحقاً

## التشغيل
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

لا يتطلب التشغيل الأولي وجود جدول قاعدة بيانات مسبق؛ ينشئ التطبيق مخطط SQLite تلقائياً داخل مجلد بيانات المستخدم.

## ملاحظات
- زر الاتصال لا يثبت حزم Android بصمت؛ تهيئة UiAutomator2 تتم بطلب واضح من المستخدم.
- كثير من عناصر الألعاب مرسومة داخل سطح رسومي ولا تظهر في شجرة Android، لذلك يوجد مسار احتياطي للصور.
- هذا إصدار تأسيسي لا يدّعي أن مهام الهجوم أو البناء مكتملة. اختبر الاتصال ولقطة الشاشة أولاً قبل إضافة إجراءات لعب آلية.
